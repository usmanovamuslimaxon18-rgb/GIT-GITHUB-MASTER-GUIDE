
# GitHub Commands Guide

## 1. What is GitHub?

GitHub is an online platform for hosting Git repositories and collaborating on projects.

## 2. Basic GitHub Commands

### Clone a Repository
```bash
git clone REPOSITORY_URL
```
Downloads a repository to your computer.

### Add Remote Repository
```bash
git remote add origin REPOSITORY_URL
```
Connects a local repository to GitHub.

### Push Changes
```bash
git push origin main
```
Uploads local commits to GitHub.

### Pull Changes
```bash
git pull origin main
```
Downloads and integrates changes from GitHub.

### View Remote Repositories
```bash
git remote -v
```
Displays connected remote repositories.

### Create and Push a Branch
```bash
git push -u origin github-guide
```
Uploads the branch to GitHub and sets its upstream.

## 3. GitHub Features

- Repositories: Store project files.
- Branches: Work on separate versions.
- Commits: Record changes.
- Pull Requests: Propose changes.
- Issues: Track tasks and problems.

## 4. Conclusion

GitHub helps developers store, share, and collaborate on projects.
