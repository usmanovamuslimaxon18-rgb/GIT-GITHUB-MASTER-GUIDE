
# Git Commands Guide

## 1. What is Git?
Git is a version control system used to track changes in files and projects.

## 2. Basic Git Commands

### Check Git Version
```bash
git --version
```
Shows the installed Git version.

### Initialize a Repository
```bash
git init
```
Creates a new Git repository.

### Check Repository Status
```bash
git status
```
Shows the current status of files.

### Add Files
```bash
git add .
```
Stages all changed files.

### Commit Changes
```bash
git commit -m "Initial commit"
```
Saves changes with a message.

### View Commit History
```bash
git log
```
Shows previous commits.

### Create a Branch
```bash
git branch git-guide
```
Creates a new branch.

### Switch Branch
```bash
git switch git-guide
```
Switches to another branch.

### Merge Branches
```bash
git merge git-guide
```
Combines changes from another branch.

## 3. Conclusion
Git helps developers track changes, manage versions, and work with branches.
