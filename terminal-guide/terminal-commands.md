
# Terminal Commands Guide

## 1. What is Terminal?

Terminal is a text-based interface used to interact with an operating system.

## 2. Basic Terminal Commands

### Print Working Directory
```bash
pwd
```
Shows the current directory.

### List Files
```bash
ls
```
Lists files and folders.

### Change Directory
```bash
cd folder-name
```
Moves into another directory.

### Create a Directory
```bash
mkdir new-folder
```
Creates a new folder.

### Create a File
```bash
touch file.txt
```
Creates an empty file.

### Remove a File
```bash
rm file.txt
```
Removes a file. Use carefully.

### Clear Terminal
```bash
clear
```
Clears the terminal screen.

## 3. Conclusion

Terminal commands help users navigate folders and manage files efficiently.
